# 新版大屏 `/screen` 设计文档

> 状态：已获用户批准（效果图 v3 确认，2026-11-16）
> 效果图基线：`OUTPUT/设计效果图_v3.html` / `预览_新版大屏设计图_v3.png`
> 实施计划：`OUTPUT/实施计划.md`

## 1. 目标

为风电损伤检测平台新增**全屏 3D 大屏入口 `/screen`**，视觉对齐参考动图（Hightopo 智慧风电监管平台），复用现有后端检测/历史/认证体系。旧界面（`/` 入口，含六套皮肤）**零改动完整保留**。

## 2. 架构决策

| 项 | 决策 |
|---|---|
| 技术路线 | 纯 HTML/CSS/JS 静态页 + FastAPI 路由（无构建步骤、无前端框架） |
| 3D 底座 | 新建 `assets/screen/farm_viewer.html`（three.js，复用 `assets/vendor/three/` 本地库），参照 `wind_turbine_viewer.html` 模式 |
| 数据层 | 直接调用 `history.py`（query_records/get_record/get_stats/can_access/update_note/delete_record/save_record）与 `app.py` 推理层（`_do_inference`/`get_image_info`/`_damage_locator_payload`/`get_risk_badge_values`/`format_summary`），不经过 Gradio 组件层 |
| 会话 | 复用 `auth.py`（`authenticate`/`create_session`/`user_for_request`——已验证兼容 FastAPI Request）与 `wd_session` Cookie |
| 产出位置 | 一切文档与交付物在 `OUTPUT/`；代码在仓库正常位置（assets/screen/、screen_api.py 等） |

## 3. 页面清单（全部对齐效果图 v3）

| 路由 | 页面 | 功能（旧版功能一项不缺） |
|---|---|---|
| `/screen/login` | 大屏登录 | 账号密码登录（auth.authenticate + create_session），成功跳 `/screen` |
| `/screen` | 检测大屏主页 | 3D 山地风场底座 + 左列（检测总览/巡检图片上传[大]/图片信息[小]）+ 右列（完整检测报告/损伤定位/历史快查）+ 底部胶囊按钮（开始分析/清空/导出报告/批量检测/历史记录）+ 场景浮动标签 |
| `/screen/batch` | 批量检测 | 多文件上传 → 逐张分析 → 进度 → 汇总导出（CSV，复用 export_tasks/exporter） |
| `/screen/history` | 历史记录 | 搜索/风险筛选/日期范围/排序/分页/详情/备注/删除/图片预览 |
| `/screen/account` | 账户中心 | 修改密码（本人）+ 用户管理（admin，增删/启停/重置/角色） |

**权限**：与旧版一致——登录必需；`/screen/account` 用户管理区仅 admin 可见；数据范围按 owner（普通用户只见自己的记录，admin 见全部）。

## 4. 主页布局规格（锁自效果图 v3）

- 画布 1920×1030 基准，`100vw/100vh` 自适应
- **3D 底座**：白天写实山地风场（天空渐变 + 云 + 三层山脉 + 山麓雾 + 阳光草谷 + 田地色块 + 树丛 + 蜿蜒土路 + 输电塔 + 升压站 + 远处风机群 + 居中单台主角风机）；OrbitControls 拖拽/缩放；损伤分析后主角风机损伤部位红色高亮 + 浮动标签
- **顶栏 64px**：发光 logo + 「智慧风电检测监管平台」+ 实时时钟 + 用户名/角色 + 返回旧版/退出
- **左右列等长**：`top:76px; bottom:96px; width:340px`；左列末位弹性给上传面板，右列末位弹性给历史快查；两列底边恒齐
- **面板语言**：深蓝半透明（rgba(10,30,56,.66)→rgba(7,20,40,.6)）+ 青描边 + 四角 L 折角 + backdrop-blur
- **浮动标签**：深蓝牌 + 青描边 + 引线，锚定 3D 坐标随视角投射（每帧 `vector.project(camera)` 更新 div 位置）
- **底部胶囊按钮排**：`bottom:26px` 居中；「开始分析」青蓝发光主按钮
- **WebGL 几何硬约束**（hud 教训）：3D canvas 容器 `position:fixed; inset:0`，任何面板/文字不得改变其屏幕几何；面板浮于其上（z-index 分层）

## 5. API 契约（screen_api.py，前缀 `/screen/api`）

| 方法/路径 | 作用 | 返回 |
|---|---|---|
| POST `/screen/login` | 表单登录 | 302 → `/screen`（失败回登录页带错误） |
| GET `/screen/api/me` | 当前用户 | `{username, role}` |
| GET `/screen/api/overview` | 检测总览 | `{total, week, high_risk, recheck, completion}` |
| POST `/screen/api/analyze` | 上传并分析单图 | `{record_id, summary, risk:{level,type,confidence}, kv:{...7项}, locator:{hasDamage,part,type,location}, image_info:{...}, recent:[...]}` |
| GET `/screen/api/records` | 历史查询 | `{rows:[...], total, stats}`（参数 search/risk/date_from/date_to/sort/page） |
| GET `/screen/api/records/{id}` | 记录详情 | 完整 JSON 报告（can_access 校验） |
| POST `/screen/api/records/{id}/note` | 保存备注 | `{ok}` |
| DELETE `/screen/api/records/{id}` | 删除记录 | `{ok}` |
| POST `/screen/api/batch` | 批量分析 | `{results:[...], summary}` |
| POST `/screen/api/change-password` | 修改密码 | 复用 `auth.change_password` |
| GET/POST `/screen/api/users`… | 用户管理 | admin-only，复用 auth 函数 |

分析流程：保存上传文件到临时目录 → `_do_inference(path)` → `save_record(..., owner_user_id, created_by)` → 组装 payload → 清理临时文件。**不改动 app.py 任何函数**，仅 import 复用。

## 7. 约束

1. 旧界面零改动：`app.py`/`ui_components.py`/现有 tests 只增不改（server.py 仅增量：include_router + 中间件白名单 + 静态挂载）
2. 85 项既有测试全程保持全绿
3. 无外部网络依赖（three.js 用本地 vendor）
4. 静态资源 `Cache-Control: no-cache`（迭代期）
5. 3D 容器几何稳定，防 WebGL 层丢失
6. 新测试 `tests/test_screen.py`，与现有测试同风格（unittest）
