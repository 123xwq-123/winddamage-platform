## 1. 项目背景与目标

将现有风电损伤检测平台的界面**完全重构**为对齐参考动图（Hightopo 风格）的智慧能源大屏形态：

- **参考 1**（`D:\Desktop\归档\参考1.gif`）：Hightopo 智慧风电监管平台 —— 全屏 3D 山地风电场 + 场景内浮动标签带引线
- **参考 2**（`D:\Desktop\归档\参考2.gif`）：图扑光储能源管理平台 —— 左右两列半透明数据面板 + 底部胶囊按钮排 + 青蓝高亮图表

**版权边界**：高保真还原布局 / 配色 / 面板 / 交互语言，不照抄 Hightopo 专有 logo 与美术资源；数据替换为风电损伤检测真实业务。

## 9. 前置历程：旧版六套皮肤的设计过程（2026-11-16，已完成）

> 六套皮肤属于旧界面（`/` 入口）的成果，新版大屏重构建立在这一历程的经验之上，故记录于此。

### 9.1 皮肤清单

| # | 皮肤 | 主题 ID | 设计语言 |
|---|---|---|---|
| 1 | 晴空 | `clear`（默认） | 浅色基线主题，所有硬编码表面 token 化后的原始形态 |
| 2 | 夜航 | `night` | 重映射 Gradio 组件 CSS 变量实现全暗色 UI（不依赖 `?__theme`） |
| 3 | 流光 | `glass` | body::after 极光径向渐变（26s 动画）+ 半透明卡片 + backdrop-blur |
| 4 | 棱格 | `bento` | Bento 网格排版：h3 20px/800、stat-num 32px/800、summary 18px/700 放大字阶 |
| 5 | 电网 | `hmi` | 工业变电站 HMI 语言：徽章形状编码（▲危险 / ■警告 / ●正常）+ 圆角按钮 |
| 6 | 深空HUD | `hud` | 融合参考 1 + 参考 2：深空海军蓝 + 科技网格 + 青色发光 + L 角折角面板 + 胶囊按钮 |

### 9.2 设计过程时间线

**主题系统（里程碑 1/3）**
- 调研 NN/g 启发式原则 + Refactoring UI 配色方法论，产出 5 套设计方案（A–E）供比选
- 将 `ui_components.py` BASE_CSS 中所有硬编码表面（卡片着色、风机天空、场区背景、危险行 hover、页面罩层）token 化
- 新增 4 个皮肤 token 块 `[data-wd-theme="night|glass|bento|hmi"]`，默认 clear
- 设置弹层加「界面风格」行（`data-wd-skin` 按钮），通过 `html[data-wd-theme]` 即时切换，`localStorage('wd_skin')` 持久化，中英词条齐备
- 验证期修复：night 空气罩层过浅（0.28→0.62–0.80）、glass 弹层半透明、glass 极光被背景 iframe 遮挡（z-index 调整）

**皮肤精修（里程碑 2/3）**
- 用户截图反馈 night 皮肤暗底暗字 → 探针证明新浏览器渲染正常（#E5EDF7），根因是旧 base.css 的浏览器缓存（max-age=3600）→ `/wd-assets/base.css` 改为 `Cache-Control: no-cache`
- night 全面加固：prose/标题/按钮/label/chip/summary 全部 `!important` 强制浅色
- bento 字阶、hmi 形状编码徽章、glass 极光动画落地

**3D 查看器联动（里程碑 3/3）**
- 父页面 `applySkin()` 经 `postTheme()` 向风机 iframe 发送 `{wdTheme:name}`（含 1500ms/5000ms 迟到 iframe 重试）
- viewer 内置每皮肤 THEME 调色板 `{sky,fog,grass,blades,vt}`，`applyTheme()` 热切换 scene.background/fog/grass 材质并切换 `html[data-vt]`；init 时读父级 `data-wd-theme`

**night 按钮对比度加固（用户截图反馈驱动）**
- 探针发现 Gradio 按钮走自己的 `.dark` 颜色变量链，仅重映射 `--button-secondary-text-color` 不够 → 强制 button span `var(--text-1) !important`、primary → #FFF
- 弹层高亮按钮（brand-500 #38BDF8 底）对比度 1.8:1 → 强制暗字 #0B1220（8.7:1）；「图片信息」chip（block-info/block-label）重映射背景（约 13:1）
- CDP 全页扫描：BAD_BUTTONS=[]、LOW_CONTRAST=[]（全部按钮 ≥3:1，多数 13+）

**第六套皮肤「深空HUD」（本项目新版大屏的直接前身）**
- 灵感来源即参考 1（面板 L 角折角、青色发光描边、发光主按钮）+ 参考 2（半透明蓝面板、左侧强调条标题、胶囊描边按钮）
- 新 token 块 `[data-wd-theme="hud"]`：`--bg-page #071426`、`--bg-card #0C2138` 等；viewer 增加 hud 调色板 `{sky:0x123055, fog:0x1b3d63, grass:0x2d5c42, vt:night}`
- TDD：TestHudSkin 7 项契约 RED→GREEN；全量 85 项测试 OK
- **canvas 黑屏 bug（重要教训）**：hud 下 3D canvas 屏上不可见（中列全黑）但像素实际正确（截角取样有 hud 天空色，切换场景像素实时变化）。经 CSSOM 规则逐条二分定位到单一规则：`[data-wd-theme="hud"] .wd-workbench-col h3 { padding-bottom:6px }` —— 该垂直尺寸改变了 3D iframe 的屏幕几何，触发 Chromium 合成器丢弃 WebGL 层。**修复**：移除该 padding 并在 BASE_CSS 留注释；有头/无头 Chrome 双重复核风机可见
- 交付：`预览_深空HUD.png`、`预览_深空HUD_设置面板.png`；入口为 设置 → 界面风格 → 深空HUD，刷新后保持

### 9.3 测试规模演进

66 项（主题前）→ 71（+5 主题契约）→ 77（+6 精修契约）→ 78（+night 按钮对比度）→ **85**（+7 hud 契约），全程保持全绿。

### 9.4 传承到新版大屏的四条经验

1. **3D 容器几何必须稳定**：不给 3D iframe 周边元素加垂直尺寸（padding/边框变化），否则 WebGL 层可能被合成器丢弃 —— 新版布局设计的硬约束
2. **静态资源 no-cache**：皮肤/样式迭代期间浏览器缓存会造成「改了没生效」的假象
3. **对比度用数字说话**：每次配色调整后 CDP 扫描全页按钮/文本对比度（≥3:1 达标）
4. **暗色皮肤需 `!important` 硬化**：Gradio 自有变量链会绕过普通重映射，prose/按钮/chip 需逐类强制
